# Bhāvanā — แอปมือถือ (iOS + Android)

แอปสวดมนต์ ห้องสมาธิ และธรรมะ สร้างด้วย Capacitor 8 จากโค้ดชุดเดียวกับเวอร์ชันเว็บ

## สิ่งที่แอปมือถือทำได้เพิ่มจากเวอร์ชันเว็บ

| ฟีเจอร์ | รายละเอียด |
|---|---|
| เสียงสวดภาษาไทย | มีไฟล์เสียงสวดในแอปครบทุกบท พร้อมไฮไลต์ตามคำ ถ้าไม่มีไฟล์ จะใช้เสียงไทยของเครื่องแทน |
| เสียงสวดจริง | ใส่ไฟล์เสียงที่อัดไว้ในแอปได้ (ดูหัวข้อ "ใส่เสียงสวดจริง") |
| แจ้งเตือนวันพระ | ๑๙.๐๐ น. ของคืนก่อนวันพระ และ ๐๖.๓๐ น. ของวันพระ แจ้งได้แม้ปิดแอปอยู่ |
| เตือนรักษาสตรีค | ๑๙.๓๐ น. ทุกวัน ข้ามวันที่นั่งสมาธิแล้ว |
| หน้าจอไม่ดับ | ระหว่างสวดและระหว่างนั่งสมาธิ |
| ใช้ออฟไลน์ได้ | ฟอนต์และบทสวดทั้งหมดอยู่ในแอป ยกเว้นลิงก์ YouTube ของพระอาจารย์ |
| ข้อมูลไม่หาย | Praylist รายการโปรด และบันทึกสมาธิ เก็บถาวรในเครื่อง |
| อื่น ๆ | ปุ่มย้อนกลับของ Android, เครื่องสั่นเมื่อนั่งสมาธิครบ, ไอคอนและหน้าเปิดแอป |

## โครงสร้างโปรเจกต์

```
www/            ตัวแอป: index.html, app.css, app.js (บทสวดและหน้าจอ), native.js (เชื่อมฟีเจอร์ของเครื่อง)
www/audio/      ไฟล์เสียงสวดจริง และ manifest.json
android/        โปรเจกต์ Android Studio
ios/            โปรเจกต์ Xcode
assets/         ไอคอนและหน้าเปิดแอปต้นฉบับ (สร้างทุกขนาดด้วย npm run assets)
scripts/        สคริปต์คัดลอกฟอนต์มาไว้ในแอป
.github/workflows/build.yml   สร้างไฟล์ติดตั้ง Android และตรวจ build iOS อัตโนมัติ
```

## ขั้นที่ 1: เอาโปรเจกต์ขึ้น GitHub

1. สร้าง repository ใหม่ที่ github.com (ตั้งเป็น Private ได้)
2. ในโฟลเดอร์นี้ (มี git commit ไว้ให้แล้ว) รันคำสั่ง:

```bash
git remote add origin https://github.com/<ชื่อผู้ใช้>/bhavana.git
```

```bash
git push -u origin main
```

## ขั้นที่ 2: ลองบน Android โดยไม่ต้องมีคอมพิวเตอร์ (เร็วที่สุด)

ทุกครั้งที่ push ขึ้น `main` ระบบ GitHub Actions จะสร้างไฟล์ติดตั้งให้เอง

1. เปิดแท็บ **Actions** ใน repo แล้วเลือกงานล่าสุดของ **Build app**
2. รอประมาณ ๕–๘ นาที แล้วดาวน์โหลด **bhavana-debug-apk** ที่ส่วน Artifacts
3. แตกไฟล์ zip แล้วส่ง `app-debug.apk` เข้ามือถือ Android กดติดตั้ง (ระบบจะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก")

งาน **iOS build check** ในหน้าเดียวกันใช้ตรวจว่าโค้ด iOS คอมไพล์ผ่าน แต่ไม่ได้ไฟล์ไปติดตั้งบน iPhone เพราะต้องเซ็นด้วยบัญชี Apple (ดูขั้นที่ 3)
ถ้า repo เป็น Private งาน iOS จะใช้โควตานาที macOS ของ GitHub ปิดได้ด้วยการลบส่วน `ios:` ในไฟล์ workflow

## ขั้นที่ 3: Build ด้วยคอมพิวเตอร์

ต้องมี Node.js 22 ขึ้นไป จากนั้นรันครั้งแรกในโฟลเดอร์โปรเจกต์:

```bash
npm install
```

### Android (Windows, Mac หรือ Linux)
1. ติดตั้ง Android Studio เวอร์ชันล่าสุด (มี JDK 21 มาในตัว)
2. รันคำสั่งนี้ ระบบจะเตรียมไฟล์แล้วเปิด Android Studio ให้
   ```bash
   npm run android
   ```
3. เสียบมือถือ (เปิด USB debugging) หรือเลือก Emulator แล้วกด ▶ Run

### iOS (ต้องใช้ Mac)
1. ติดตั้ง Xcode เวอร์ชันล่าสุดจาก App Store
2. รันคำสั่งนี้ ระบบจะเปิด Xcode ให้
   ```bash
   npm run ios
   ```
3. เลือก target **App** › **Signing & Capabilities** › เลือก **Team** (Apple ID ส่วนตัวใช้ลองบนเครื่องตัวเองได้ฟรี ๗ วัน)
4. เสียบ iPhone แล้วกด ▶ Run

ทุกครั้งที่แก้ไฟล์ใน `www/` ให้รัน `npm run sync` ก่อน build ใหม่

## ขั้นที่ 4: ส่งขึ้น App Store และ Google Play

**ก่อนส่ง: เปลี่ยนรหัสแอปเป็นของคุณเอง** รหัสตอนนี้ `com.bhavana.app` เป็นรหัสชั่วคราว ต้องไม่ซ้ำกับแอปอื่นในโลก เช่น `com.ชื่อคุณ.bhavana` ต้องแก้ ๓ ที่:
- `capacitor.config.json` → `appId`
- `android/app/build.gradle` → `applicationId`
- Xcode → target App → General → **Bundle Identifier**

### Google Play (ค่าสมัคร 25 ดอลลาร์ ครั้งเดียว)
1. สมัคร Google Play Console
2. Android Studio › **Build › Generate Signed App Bundle** › สร้าง keystore ใหม่ ⚠️ เก็บไฟล์ keystore และรหัสผ่านไว้ให้ดี ถ้าหาย จะอัปเดตแอปไม่ได้อีก
3. สร้างแอปใน Play Console แล้วอัปโหลดไฟล์ `.aab` ไปที่ **Internal testing** ก่อน
4. กรอกข้อมูลต่อไปนี้:
   - Data safety: แอปไม่ได้เก็บหรือส่งข้อมูลออกนอกเครื่อง
   - Content rating
   - Privacy policy URL (ต้องมี จะใช้หน้าเว็บสั้น ๆ ก็ได้)
5. Google จะให้บัญชีส่วนตัวที่สมัครใหม่เปิดทดสอบแบบ Closed testing (ผู้ทดสอบ ๑๒ คน นาน ๑๔ วัน) ก่อนเปิดให้ทุกคนดาวน์โหลด

### App Store (Apple Developer Program 99 ดอลลาร์ ต่อปี)
1. สมัคร Apple Developer Program
2. สร้างแอปใน App Store Connect โดยใช้ Bundle ID เดียวกับใน Xcode
3. Xcode › **Product › Archive** › **Distribute App** › App Store Connect
4. ทดสอบผ่าน TestFlight แล้วจึงกรอกข้อมูลร้านค้า:
   - ภาพหน้าจอ iPhone 6.9 นิ้ว
   - App Privacy: Data Not Collected
5. กด Submit for Review

## Premium (ซื้อครั้งเดียว 1.99 AUD)

**เวอร์ชันฟรี** สวดได้วันละ ๓ บท นับเป็นบทที่ไม่ซ้ำกัน (สวดบทเดิมซ้ำไม่นับเพิ่ม) ฟังธรรมะและนั่งสมาธิได้ไม่จำกัด
**Premium** สวดไม่จำกัด ใช้รายการโปรดได้ และสร้าง Praylist ของตัวเองได้

- การซื้อผ่านบัญชี Apple ID หรือ Google Play ของผู้ใช้โดยตรง ไม่ต้องสมัครบัญชีกับแอป ไม่มีเซิร์ฟเวอร์
- ใช้ปลั๊กอิน `@capgo/native-purchases` (StoreKit 2 / Google Play Billing)
- เปลี่ยนเครื่องใหม่ ให้กด **กู้คืนการซื้อ** (Apple กำหนดให้แอปต้องมีปุ่มนี้)
- เวอร์ชันเว็บไม่ล็อกฟีเจอร์ ถ้าอยากลองเป็นผู้ใช้ฟรี ให้เปิด **การตั้งค่า › จำลองผู้ใช้ฟรี**

### ตั้งค่าในร้านค้า (รหัสสินค้า `premium_lifetime` ต้องตรงกันทั้งสองร้าน)

**App Store Connect**
1. ก่อนอื่น เซ็นสัญญา **Paid Apps Agreement** และกรอกข้อมูลบัญชีธนาคารและภาษีให้ครบ (เมนู Business) ถ้ายังไม่ทำ จะขายของในแอปไม่ได้
2. เปิดแอป › **Monetization › In-App Purchases** › กด ➕ แล้วเลือก **Non-Consumable**
   - Reference Name: `Bhavana Premium`
   - Product ID: `premium_lifetime`
3. Price Schedule:
   - เลือกประเทศหลักเป็น **Australia** ที่ราคา **A$1.99**
   - Apple จะคำนวณราคาของประเทศอื่นให้เอง ถ้าต้องการราคาไทยแบบตายตัว ให้ตั้ง Thailand เป็น **฿49** (หรือราคาที่ใกล้ที่สุดในรายการ)
4. ใส่ชื่อและคำอธิบายภาษาไทย/อังกฤษ และภาพหน้าจอหน้า Premium สำหรับ Review
5. Xcode › target App › **Signing & Capabilities** › **+ Capability** › **In-App Purchase**
6. ทดสอบด้วยบัญชี **Sandbox** (Users and Access › Sandbox) บน iPhone จริง หรือผ่าน TestFlight

**Google Play Console**
1. ก่อนอื่น ตั้งค่า **Payments profile** (บัญชีผู้ค้า) ให้เรียบร้อย
2. อัปโหลด build ที่มีโค้ดนี้ขึ้น Internal testing ก่อน ปุ่มสร้างสินค้าจะเปิดหลังจากนั้น

## ห้องสนทนาธรรม (แท็บที่ ๒)

สมาชิก Premium ตั้งคำถามเรื่องชีวิตประจำวัน ตอบคำถามของคนอื่น และกด 🙏 สาธุได้ ส่วนผู้ใช้ฟรีอ่านได้อย่างเดียว

### สิ่งที่มีในห้อง
- **ชื่อที่แสดง:** ผู้ใช้ตั้งเองตอนโพสต์ครั้งแรก ไม่ต้องใช้ชื่อจริง และต้องยอมรับกติกาก่อนโพสต์
- **หมวดคำถาม:** ครอบครัว · การงาน · ความรัก · สุขภาพใจ · การภาวนา · ทั่วไป และมีตัวกรอง "รอคำตอบ"
- **ความปลอดภัย** (Apple กำหนดไว้สำหรับแอปที่ผู้ใช้โพสต์เนื้อหาเองได้):
  - คัดกรองคำหยาบและลิงก์
  - ปุ่มรายงานโพสต์ โพสต์ที่ถูกรายงานครบ ๓ ครั้งจะถูกซ่อนอัตโนมัติ
  - ซ่อนโพสต์จากผู้ใช้ที่ไม่อยากเห็น
  - ลบโพสต์ของตัวเองได้
  - แบนผู้ใช้ได้จากตาราง `banned_users`
- **ข้อความแนะนำ:** ด้านบนห้องแสดงเบอร์สายด่วนสุขภาพจิต 1323 ไว้เสมอ

### ตั้งค่า Supabase (ฟรี ประมาณ ๑๐ นาที)
1. สมัครที่ supabase.com แล้วสร้าง Project ใหม่ (เลือก Region **Southeast Asia (Singapore)**)
2. เปิด **SQL Editor** วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด แล้วกด **Run**
3. ไปที่ **Authentication › Sign In / Providers** แล้วเปิด **Allow anonymous sign-ins**
   - แต่ละเครื่องจะได้บัญชีของตัวเองอัตโนมัติ ผู้ใช้ไม่ต้องกรอกอีเมล
4. ไปที่ **Project Settings › API** คัดลอก **Project URL** และ **anon public key** มาใส่ใน `www/config.js`
   - anon key ออกแบบมาให้ใส่ในแอปได้ ⚠️ **ห้ามใส่ service_role key** เด็ดขาด
5. รัน `npm run sync` แล้ว build ใหม่

### ดูแลห้อง
ทำผ่าน Supabase › **Table Editor**:
- **ดูโพสต์ที่ถูกซ่อน:** ตาราง `questions` และ `answers` ช่อง `hidden = true`
- **เปิดโพสต์กลับ:** แก้ `hidden` เป็น `false`
- **แบนผู้ใช้:** คัดลอก `author` ของโพสต์ แล้วเพิ่มเป็นแถวใหม่ในตาราง `banned_users`

### ข้อควรรู้
- แอปเช็ก Premium ในเครื่อง ผู้ที่เขียนโปรแกรมเรียกเซิร์ฟเวอร์ตรง ๆ อาจโพสต์ได้โดยไม่ซื้อ Premium สำหรับห้องขนาดเล็กถือว่ายอมรับได้ ถ้าต้องการปิดช่องนี้ ต้องเพิ่ม Supabase Edge Function ที่ตรวจใบเสร็จจาก App Store / Google Play ก่อนให้สิทธิ์โพสต์
- บัญชีผูกกับเครื่อง ถ้าลบแอปหรือเปลี่ยนเครื่อง จะได้ชื่อในระบบใหม่ แต่โพสต์เดิมยังอยู่ในห้อง
- ส่งแอปขึ้น App Store: ในช่อง Review Notes ให้อธิบายว่ามีระบบรายงาน ซ่อน และแบนผู้ใช้ตามข้อกำหนด 1.2 (User-Generated Content) และกรอก Privacy ว่ามีการเก็บ "User Content"

## ถ้าแอปยังไม่มีเสียงสวด

แอปใช้เสียงอ่านภาษาไทยของระบบ ถ้าในเครื่องยังไม่มีเสียงไทย:
- **iPhone:** การตั้งค่า › การช่วยการเข้าถึง › เนื้อหาที่พูด › เสียง › ไทย › ดาวน์โหลด **Kanya** (แนะนำแบบ "ปรับปรุง" เพราะเสียงชัดกว่า)
- **Android:** ในแอปจะมีปุ่ม **ติดตั้งเสียงภาษาไทย** ให้กด หรือไปที่ การตั้งค่า › ระบบ › ภาษา › เอาต์พุตการอ่านออกเสียง › Google › ติดตั้งข้อมูลเสียง › ไทย

ระหว่างที่ยังไม่มีเสียง แอปจะไล่ไฮไลต์ทีละคำ ให้สวดตามได้ด้วยตัวเอง

## เสียงสวดที่สร้างไว้ในแอป

โฟลเดอร์ `www/audio/` มีไฟล์เสียงสวดครบทุกบท และเสียงบรรยายหัวข้อธรรมทุกหัวข้อ สร้างด้วย **Azure Speech เสียง "นิวัฒน์" (th-TH-NiwatNeural)** ใช้ผู้พูดคนเดียวทั้งแอป
- ไฟล์เสียงอยู่ในตัวแอป จึงมีเสียงสวดทุกเครื่อง แม้เครื่องจะไม่มีเสียงไทย
- ไฮไลต์ตรงทุกคำ เพราะ Azure ส่งเวลาของแต่ละบรรทัดและแต่ละคำมาให้
- **จังหวะสวดสม่ำเสมอ** สวดตามได้ง่าย ทุกพยางค์ยาวเท่ากัน หยุดสั้นระหว่างคำ และหยุดยาวขึ้นตรงจุลภาคกับท้ายบรรทัด
  - สวดปกติ: ประมาณ ๓๓๐ มิลลิวินาทีต่อพยางค์
  - สวดช้า: ประมาณ ๔๓๐ มิลลิวินาทีต่อพยางค์
  - วิธีทำ: สคริปต์ให้ Azure สร้างเสียง วัดความยาวจริงของแต่ละคำ ปรับความเร็วรายคำจนพยางค์เท่ากัน แล้วตัดแต่ละคำมาเรียงใหม่ด้วยช่วงหยุดที่กำหนดเอง
  - ปรับตัวเลขได้ใน `STYLES` (`syl_ms`, `word_ms`, `comma_ms`, `gap`)
- โหมด "สวดช้า ก้องแบบในโบสถ์" ใช้เสียงเดียวกัน แค่ช้าลง ทุ้มลงเล็กน้อย และใส่เสียงก้อง
- คำบรรยายธรรมะใช้จังหวะพูดตามธรรมชาติ
- เสียงที่สร้างจาก Azure ใช้ในแอปเชิงพาณิชย์ได้ ตามเงื่อนไขบริการของ Microsoft

### สร้างเสียงใหม่หลังแก้ตัวบท
1. ไปที่ Azure Portal › Speech resource › **Keys and Endpoint** เพื่อดู KEY 1 และ Region
2. รันคำสั่ง:
```bash
pip install azure-cognitiveservices-speech
```
```bash
AZURE_SPEECH_KEY=<KEY 1> AZURE_SPEECH_REGION=southeastasia python3 scripts/generate_audio_azure.py --only itipiso
```
- ไม่ใส่ `--only` = สร้างใหม่ทุกบท ใช้ประมาณ 40,000 ตัวอักษรต่อครั้ง ยังอยู่ในโควตาฟรีของแพ็กเกจ F0 (500,000 ตัวอักษรต่อเดือน)
- ปรับความเร็ว ระดับเสียง และช่วงหยุด ได้ที่ `STYLES` ในไฟล์สคริปต์
- อยากสร้างเสียงแบบออฟไลน์ ใช้ `scripts/generate_audio.py` (โมเดล MMS-TTS) ได้ แต่โมเดลนั้นใช้เชิงพาณิชย์ไม่ได้ (CC-BY-NC 4.0)

## ใส่เสียงสวดจริง (เสียงฆราวาส / เสียงพระสวด)

1. วางไฟล์ `.mp3` หรือ `.m4a` ใน `www/audio/` โดยหนึ่งไฟล์คือการสวดหนึ่งรอบของหนึ่งบท
2. เพิ่มรายการใน `www/audio/manifest.json` ใช้รหัสบทสวด (`id` ใน `app.js`) เป็นชื่อหัวข้อ:

```json
{
  "itipiso": {
    "lay": "itipiso-lay.mp3",
    "monk": "itipiso-monk.mp3",
    "cues": { "lay": [0, 4.2, 8.0, 12.5, 16.1, 19.8, 22.9, 26.0, 29.2, 33.0, 36.4, 38.9, 43.5] }
  }
}
```

- `lay` คือไฟล์สำหรับเสียงฆราวาส ส่วน `monk` คือไฟล์สำหรับเสียงพระสวด จะใส่แค่อย่างใดอย่างหนึ่งก็ได้
- `cues` ไม่บังคับ ใส่เป็นวินาทีที่เริ่มแต่ละบรรทัดในรอบแรก (ไม่นับบรรทัดคำอธิบายในวงเล็บ) ถ้าไม่ใส่ แอปจะเลื่อนบรรทัดตามสัดส่วนความยาวของคำ
- ถ้าบทนั้นสวดหลายจบ (เช่น ๙ จบ) แอปจะเล่นไฟล์ซ้ำตามจำนวนจบเอง
- บทที่ยังไม่มีไฟล์เสียง จะใช้เสียงอ่านของเครื่องแทน
- ⚠️ ใช้เฉพาะเสียงที่อัดเองหรือได้รับอนุญาตแล้วเท่านั้น

รหัสบทสวดที่ใช้บ่อย: `namo` `trisarana` `sila5` `itipiso` `ngoenlan` `chinabanchon` `jaya` `karaniya` `mongkol` `bojjhanga` `metta_all` `uthit` `kruadnam`

## แก้ไขบทสวดหรือเนื้อหา

- เนื้อหาทั้งหมดอยู่ใน `www/app.js`
  - `CH` คือบทสวด
  - `SETS` คือชุดบทสวด
  - `MOODS` คือความรู้สึก
  - `TEACHERS` และ `TOPICS` คือพระอาจารย์และหัวข้อธรรม
- บรรทัดที่ขึ้นต้นด้วย `~` คือคำอธิบาย แสดงบนจอแต่ไม่อ่านออกเสียง
- ค่า `o` คือลำดับขั้นการสวด แอปใช้ค่านี้จัดเรียง Praylist ให้อัตโนมัติ
